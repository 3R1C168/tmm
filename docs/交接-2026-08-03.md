## 9. 重要教训（本会话）

1. **fix 后必须重建部署**：`b836ae1b`（final review 修复）当时没重构建，导致用户跑旧二进制遇到 .tmp 删除 bug——修复代码要跟进制部署
2. **压测并发进程是灾难**：多次 dispatch subagent 产生 23+ 孤儿 stress 进程共享文件互相覆盖——压测只允许一个执行者，进程清理要验证到 0
3. **curl 传中文会乱码**：Git Bash curl 的 `-d` 传 UTF-8 中文会 mangle 成非法字节——测试中文用 node 或文件
4. **Go `filepath.Ext` 结尾点**：`Ext("xxx.")` 返回 `"."` 非空，判断有效扩展名要排除
5. **压测脚本双重缩放 bug**：按比例抽样后又按请求数缩放，比例从 17% 压到 1%——抽样逻辑要单一维度
