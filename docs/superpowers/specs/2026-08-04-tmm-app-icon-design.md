# Telegram 消息管理器程序图标设计

日期：2026-08-04
状态：设计已确认

## 目标

为“Telegram 消息管理器”制作一套统一的现代扁平图标，用于 Vue/Vite 网页和 Windows EXE。程序主要用于查看、下载、上传和管理 Telegram 消息。

## 最终视觉方案

采用视觉探索中的原始 **G · 电光紫消息切面**，不应用后续圆角、气泡、纸飞机或其他变体。

图标由以下元素组成：

- 电光紫渐变圆角方形底板。
- 中央白色抽象消息切面：左右展开的几何形体，融合消息卡片、发送方向和折纸切面语义。
- 左侧紫色内切面，形成进入与流动感。
- 右侧浅紫内切面，增强结构层次。
- 左侧一个深紫圆点，暗示消息起点或数据节点。

该图形刻意不使用 Telegram 官方蓝，也不直接复刻官方纸飞机轮廓，从而建立独立品牌识别。

## 颜色

- 渐变起点：`#9C5CF0`
- 渐变终点：`#5133A6`
- 常用中间紫：`#7045C4`
- 左侧内切面：`#C8A7F6`
- 右侧浅切面：`#F4EEFF`
- 主图形高光：`#FFFFFF` 至 `#E6D7FF`
- 起点圆点：`#6841BE`

## 几何与风格

- 基准画布：`256 × 256`。
- 底板边距：`16px`，尺寸 `224 × 224`。
- 底板圆角：`54px`。
- 主图形保持原 G 方案的直线切面和尖头，不进行圆角化。
- 图形视觉居中，并保留足够安全边距，避免 Windows 图标蒙版和浏览器裁切。
- 风格为现代、扁平、清晰；允许底板与白色主图形使用轻微渐变，不加入拟物高光、描边或复杂阴影。

## 输出资产

正式资产包括：

- `icon.svg`：可编辑矢量母版，256×256 viewBox。
- `icon-16.png`
- `icon-24.png`
- `icon-32.png`
- `icon-48.png`
- `icon-64.png`
- `icon-128.png`
- `icon-256.png`
- `icon-512.png`
- `favicon.ico`：至少包含 16、24、32、48px。
- `app.ico`：Windows EXE 图标，包含 16、24、32、48、64、128、256px。
- `apple-touch-icon.png`：180×180。

小尺寸版本允许减少内部浅紫分面，但不得改变原 G 的外轮廓和紫色品牌识别：

- 16px：保留紫色底板与白色主轮廓；可省略圆点和内部浅切面。
- 24–32px：保留圆点和主要双色切面，简化最细的层次。
- 48px 及以上：完整呈现原 G 图形。

## 项目接入范围

- Vue/Vite 网页：在 `web/app/index.html` 接入 favicon、SVG/PNG 图标和 Apple Touch Icon。
- Windows EXE：为 `tmm.exe` 嵌入 `app.ico`；选择与现有 Go/Windows 构建流程兼容的最小方案。
- 不把图标扩展成完整 PWA，也不新增 Web App Manifest，除非项目已有实际安装需求。
- 不修改现有 Art Design Pro 的 UI 主色 `#4f7cff`；程序图标使用独立紫色品牌色。

## 验收标准

- 图标与原 G 视觉方案一致，无后续圆角或纸飞机变体。
- 在 16、24、32、48px 下仍能识别为独立的消息/数据传输符号。
- 在 Windows 浅色与深色任务栏、浏览器浅色与深色标签栏上边界清晰。
- 网页 favicon 实际显示。
- Windows 资源管理器和任务栏中的 `tmm.exe` 实际显示新图标。
- SVG、PNG 和 ICO 的颜色与几何保持一致。
