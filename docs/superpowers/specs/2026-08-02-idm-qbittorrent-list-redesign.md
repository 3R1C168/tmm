# IDM/qBittorrent 风格下载列表重构

日期：2026-08-02
范围：任务页（`web/app/src/views/Tasks.vue`）从卡片式重构为 IDM/qB 风格表格列表。

## 目标

把当前「任务卡纵向堆叠」改成 IDM + qBittorrent 风格的「文件级表格列表」：
- 一行 = 一个文件（不是任务），信息平铺可见
- 左侧分类侧边栏（状态 + 频道/群组来源 + 活动），双维度叠加筛选
- 可配置列（列设置按钮点开勾选）
- 来源分组头（可折叠，聚合信息）
- 紧凑表格行（qB 风格）
- 底部全局状态栏

## 非目标（留作后续）

- **下载历史/去重提醒**：记录每个下载过的 (频道, msgID)，新建任务时提醒已下载。本期「频道/群组」分类仅从现有 task.files 动态汇总；历史功能作为独立后续项。
- **文件级 pause/resume API**：勾选文件后操作仍作用于所属 task（自动去重），后端不加文件级接口。这是交接文档 R3-2，留作后续。

## 布局

三栏 + 底部状态栏：

```
┌──────────┬─────────────────────────────────────────────┐
│ 侧边栏    │  工具栏：⏵开始 ⏸暂停 🗑删除 ⚙列设置            │
│ (分类)   ├─────────────────────────────────────────────┤
│          │  表头：☑ │ 文件名 │ 来源 │ 大小 │ 进度 │ ...   │
│          ├─────────────────────────────────────────────┤
│          │  ▼ 群A · 4文件 · 2.3/4.8G · 48% · 18MB/s     │
│          │    ☑ video_3187.mp4  群A  1.1G ──35% ...      │
│          │  ▼ 群B · 2文件 · 0/220M · 排队                │
│          │    ☑ doc_3179.pdf    群B  200M ──0%  ...      │
├──────────┴─────────────────────────────────────────────┤
│  状态栏：12 文件 · ↓ 18.5 MB/s · 已下载 2.3 GB / 5.0 GB │
└──────────────────────────────────────────────────────┘
```

- 左侧边栏：固定窄列（~140px），分类树带数量徽标，点筛选列表。
- 中间主区：工具栏 + sticky 表头 + 滚动列表，表格占满剩余宽度。
- 底部状态栏：全局汇总，固定视口底部。

## 组件设计

### 1. 侧边栏（左）

三个分区，双维度叠加筛选（状态 × 来源 可同时生效）：

```
状态
  全部        12
  下载中       3
  已完成       8
  已暂停       1
  失败         0
─────────────
频道/群组
  群A          4
  资源社区      6
  频道B         2
─────────────
活动
  活跃         3
  非活跃       9
```

- **状态区**：单选互斥（点一个切换），文件级状态统计。
- **频道/群组区**：从当前 store 所有 task.files 的 fromName/fromID 动态汇总。任务删除后若某来源无文件则消失。单选互斥，或「全部」清除筛选。
- **活动区**：活跃 = 有速率(running 且 speed>0)；非活跃 = 速率=0。单选互斥。
- **双维度叠加**：状态区选「下载中」+ 频道区选「群A」= 只显示群A 中正在下载的文件。同一分区内单选，不同分区叠加。
- 数量徽标实时更新（基于拍平后的文件行统计）。

### 2. 工具栏（主区顶部）

`⏵开始  ⏸暂停  🗑删除  |  ⚙列设置`

- 图标按钮（lucide 图标，复用现有图标体系），悬停 tooltip。
- 开始/暂停/删除作用于勾选的文件行所属的 task（自动去重）。例：勾了群A 的 2 文件点暂停 → 暂停整个群A 任务。
- 列设置按钮点开一个 popover，勾选要显示的列。
- 表头最左是「全选」复选框（勾选当前筛选视图内所有文件行）。

### 3. 表格（表头 + 行）

#### 列定义（可配置）

| 列 key | 默认显示 | 内容 | 宽度策略 |
|---|---|---|---|
| check | 是 | 复选框 | 固定 32px |
| name | 是 | 文件名+状态图标，左对齐 | 弹性 flex:1，省略号 |
| source | 是 | fromName | 固定 ~120px |
| size | 是 | 总大小（fmtBytes） | 固定 ~80px |
| progress | 是 | 进度条+百分比 | 弹性 flex:1 或固定 ~160px |
| speed | 是 | MB/s | 固定 ~80px |
| downloaded | 否 | 已下/总 | 固定 ~130px |
| status | 是 | 文字标签 | 固定 ~70px |

- 列配置存 localStorage（key 如 `tmm.taskColumns`），记住用户选择。
- 表头 sticky（`position: sticky; top: 0`），列表滚动时表头不动。

### 4. 来源分组头

```
▼ 群A · 4 文件 · 2.3 GB / 4.8 GB · 48% · ↓ 18.5 MB/s
```

- 按 fromName 分组（同来源的连续文件行归一组）。
- 聚合信息：文件数、总已下/总大小、总进度百分比、聚合速率。
- 点击 ▼/▶ 折叠/展开，状态存 localStorage（key 如 `tmm.collapsedGroups`）。
- 折叠后该组文件行隐藏，只留分组头（分组头本身仍显示，方便看聚合状态）。

### 5. 紧凑表格行（qB 风格）

- 行高 ~32px，细分割线（`border-bottom: 1px solid var(--border)`）。
- 悬停浅灰高亮（`var(--bg-hover)`），选中行浅蓝底。
- 数字列右对齐 + `font-variant-numeric: tabular-nums`（防数字跳动）。
- 进度条复用 el-progress（stroke-width 4）。
- 状态列用 el-tag（复用现有 statusText/tagType）。

### 6. 底部状态栏

```
12 文件 · 3 下载中 · ↓ 18.5 MB/s · 已下载 2.3 GB / 5.0 GB
```

- 固定底部（不随列表滚动）。
- 总文件数、下载中数、总速率（所有 running 文件速率之和）、总已下/总大小。
- 速率复用后端 task.Speed（每秒采样，已有）。

## 数据流

### 拍平文件行

现有 `store.tasks` 是 `Task[]`，每个 Task 有 `files: FileEntry[]`。前端 computed 把它们拍平：

```js
// 伪代码
const rows = computed(() => {
  const out = []
  for (const t of store.tasks) {
    for (const f of t.files) {
      out.push({
        taskId: t.id,
        taskStatus: t.status,
        taskSpeed: t.speed,
        file: f,            // FileEntry
        source: f.fromName, // 分组+筛选用
      })
    }
  }
  return out
})
```

### 筛选管道

```
rows → 按状态筛选 → 按来源筛选 → 按活动筛选 → 排序 → 分组渲染
```

- 状态筛选：file.status 匹配侧边栏状态选择
- 来源筛选：file.fromName 匹配侧边栏频道/群组选择
- 活动筛选：taskSpeed > 0 为活跃
- 排序：默认按创建时间倒序（保留现有），后续可加表头点击排序
- 分组：按 fromName 分组，每组前插分组头

### 勾选与操作

- 勾选态按 **文件行唯一键**（`taskId/fileKey`）跟踪，切筛选不丢（复用现有 selected Set 模式）。
- 点开始/暂停/删除：从勾选行提取 taskId 去重 → 调 batchAction(ids, action)（复用现有 API）。
- 删除复用现有 el-dialog（同时删文件单选）。

## 复用清单

| 现有部分 | 处理 |
|---|---|
| 删除对话框（el-dialog + 同时删文件） | 完全复用 |
| CSS 变量（--border/--bg-panel/--text-2/--shadow 等） | 完全复用 |
| 状态标签 el-tag（statusText/tagType） | 复用，放状态列 |
| fmtBytes/fmtTime/percent 等 helper | 复用 |
| 批量操作 API（batchAction） | 复用，操作粒度 task 级（文件行→taskId 去重） |
| lucide 图标体系 | 复用，工具栏图标按钮 |
| 后端 Speed 采样（每秒 EWMA） | 复用，状态栏+分组头聚合 |

不復用：chip 形态（改表格单元格）、卡片布局、gap 间距体系（改列宽控制）。

## 后端改动

**无**。本次纯前端重构，所有数据来自现有 API：
- `GET /api/tasks` 返回 tasks（含 files）
- SSE 推送 task 快照（含 files 状态/进度/速率）
- 批量操作 API（pause/resume/delete）作用于 task 级

## localStorage 键

| key | 内容 |
|---|---|
| `tmm.taskColumns` | 列显隐配置 `{ name:true, source:true, ... }` |
| `tmm.collapsedGroups` | 折叠的分组名 Set |
| `tmm.sidebarFilter` | 当前筛选状态（状态/来源/活动选择） |

## 不确定点 / 待实现时决策

1. **进度列宽度**：弹性（和文件名列一起 flex:1 撑开）还是固定（~160px）。实现时看效果定，倾向固定，避免两个弹性列互相挤。
2. **表头排序**：本次是否加「点列头排序」。倾向不加（YAGNI），保持范围聚焦；后续可加。
3. **空状态**：无文件时显示什么。复用 el-empty，文案「暂无下载，在消息页选择媒体下载」。
